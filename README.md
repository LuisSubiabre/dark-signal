# DARK SIGNAL

Guía interactiva de producción para un track de electrónica oscura (cyberpunk / dark ambient / focus) pensada para usarse en un segundo monitor junto a Ableton Live 12.

## Stack

React · TypeScript · Vite · Tailwind CSS

## Comandos

```sh
npm install
npm run dev
npm run build
npm run preview
```
